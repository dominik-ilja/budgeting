# Node packages

## Dependencies

| Package        | Purpose                                                                         |
| -------------- | ------------------------------------------------------------------------------- |
| bcrypt         | Securely hashes passwords before storing them.                                  |
| better-sqlite3 | Fast, synchronous SQLite library for database operations.                       |
| cross-env      | Sets environment variables consistently across platforms (Windows, Unix, etc.). |
| csv-parser     | Parses CSV files.                                                               |
| dotenv         | Loads environment variables from a `.env` file into `process.env`.              |
| express        | Web framework used to build the HTTP API layer.                                 |
| jsonwebtoken   | Creates and verifies JSON Web Tokens for authentication.                        |
| multer         | Middleware for handling file uploads via HTTP forms.                            |
| zod            | Runtime validation and parsing of data using schema definitions.                |

## Development Dependencies

| Package                          | Purpose                                                                     |
| -------------------------------- | --------------------------------------------------------------------------- |
| @eslint/js                       | ESLint base rules for JavaScript projects.                                  |
| @types/*                         | Provides TypeScript type definitions for packages that lack built-in types. |
| eslint                           | Linting tool to maintain code quality and style.                            |
| eslint-plugin-simple-import-sort | Automatically sorts import statements for consistency.                      |
| jest                             | Testing framework used for writing and running tests.                       |
| supertest                        | Simplifies testing HTTP endpoints in Express apps.                          |
| ts-jest                          | Allows Jest to run TypeScript files directly.                               |
| tsx                              | Fast runner for TypeScript/TSX with ESM support; useful for scripts.        |
| typescript                       | Adds static typing and compiles `.ts` files to JavaScript.                  |
| typescript-eslint                | Enables ESLint to understand and lint TypeScript code.                      |
